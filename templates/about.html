About the Project

EduPath: Student Success Predictor is a Machine Learning project that predicts whether a student will PASS or FAIL based on academic performance and study habits.

Project Details

Project Title: EduPath: Student Success Predictor

Machine Learning Technique: Classification

Algorithm: Decision Tree Classifier

Dataset: University Students Performance and Study Habits 2026

Programming Language: Python

Framework: Flask

Libraries: Pandas, NumPy, Scikit-learn and Joblib

Project Objective

The main objective is to analyse student information and predict their academic result using a trained Machine Learning model.

Pass and Fail Criteria

For this project, a final exam score of 80 or above is considered PASS. A score below 80 is considered FAIL.
